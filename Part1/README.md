# Part 1 — Individual conditionals exercises

Start here after the demo. Work in numerical order and write your own code.
Aim for exercises 1–3 in this lab; attempt 4 if time allows and continue
unfinished work next lab.

| Exercise | Focus | Extra checks |
| --- | --- | --- |
| [1_Orwell.py](1_Orwell.py) | `if` and equality | 1984 and 1983; only the first prints Orwell. |
| [2_Absolute.py](2_Absolute.py) | A negative number and its opposite | -7, 0, 7. Use a condition rather than `abs()`. |
| [3_Order.py](3_Order.py) | Several independent conditions | 9, 10, 99, 100, 999, 1000. More than one message may apply. |
| [4_Calculator.py](4_Calculator.py) | Choose an operation from text | All three operations, then an unsupported operation. |

For each task: identify inputs → choose their types → write the conditions
→ display results → test every sample and the boundary values.

Read [If and indentation](https://www.w3schools.com/python/python_conditions.asp),
[Comparisons](https://www.w3schools.com/python/python_operators_comparison.asp),
[Else](https://www.w3schools.com/python/python_if_else.asp) and
[Elif](https://www.w3schools.com/python/python_if_elif.asp) as needed.

Use `:` after each condition and four spaces for the block.
Remember: `=` assigns a value; `==` compares two values.
Run each file on its own; see the [main instructions](../README.md).
