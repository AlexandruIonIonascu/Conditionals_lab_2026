# Recap — 30 minutes

Start here, even if you did not finish the previous lab. Write the solutions
yourself, using variables, `input()`, `print()` and simple arithmetic.
Each file has reading links, steps and sample checks.

| Time | Exercise | Practise |
| --- | --- | --- |
| 5 min | [01_variables.py](01_variables.py) | Store, display and change values. |
| 5 min | [02_input.py](02_input.py) | Read text and keep two answers in separate variables. |
| 8 min | [03_integer_input.py](03_integer_input.py) | Convert text to integers and add them. |
| 8 min | [04_decimal_input.py](04_decimal_input.py) | Convert a decimal price and an integer quantity; multiply. |
| 4 min | Review together | Explain the types and correct one mistake. |

Run one file at a time from the repository root, for example:

```bash
python recap/03_integer_input.py
```

Before the demo, be ready to explain:

- What value does each variable store?
- What type does `input()` return, even when you type a number?
- Why does adding two numeric inputs require `int()` or `float()`?
- Why use `float()` for a price such as `2.5`?

You do not need `if`, loops, functions or f-strings here.
Use `print()` with commas to display text and numbers together.
Ask the instructor for help if you cannot run or explain exercises 3–4.
